# 🎀 공주핑트 (Exercise Princess)

운동을 기록하면 **몰락한 공주님이 빚을 갚고 왕궁으로 돌아가는** 아기자기한 게임형 운동 습관 앱이에요.

## 📖 스토리

왕국이 무너지고 빚 **1,000,000G**를 떠안은 채 다 쓰러져가는 오두막에서 시작하는 공주님.
하루 한 번 운동을 기록할 때마다 골드를 벌어 빚을 갚고, 점점 좋은 집으로 이사하며
마지막엔 **왕국을 되찾은 여왕님**이 됩니다! 👑

### 성장 단계

| 단계 | 집 | 조건 |
|---|---|---|
| 1 | 🏚️ 다 쓰러져가는 오두막 | 시작 |
| 2 | 🛖 비는 안 새는 오두막 | 빚 250,000G 상환 |
| 3 | 🏠 아담한 시골집 | 빚 500,000G 상환 |
| 4 | 🏡 정원이 있는 집 | 빚 750,000G 상환 |
| 5 | 🏘️ 마을에서 제일 예쁜 집 | 빚 전액 청산! |
| 6 | 🏛️ 우아한 저택 | 자산 250,000G |
| 7 | 🏰 언덕 위의 성 | 자산 500,000G |
| 8 | 👑🏰 찬란한 왕궁 | 자산 1,000,000G |

## 💰 골드 규칙

- 운동 1분당 **1,000G** (1회 최대 120분 인정)
- 하루 첫 운동 보너스 **+10,000G**
- 연속 출석 보너스 **+1,000G × 연속일수** (최대 +30,000G)
- 골드는 빚부터 자동으로 갚고, 남는 건 자산으로 쌓여요

매일 30분씩 운동하면 약 한 달 만에 빚을 다 갚을 수 있는 밸런스예요. 🔥

## ✨ 주요 화면

- **공주님의 집** — 현재 집과 공주님 상태, 남은 빚/모은 자산, 다음 집까지의 진행률
- **운동 기록** — 8가지 운동 종류, 시간 선택, 한 줄 일기, 예상 보상 미리보기
- **운동 일기** — 전체 기록과 통계(총 횟수/시간/연속일), 밀어서 삭제
- **성장 스토리** — 전체 로드맵과 잠금 해제 현황
- **이사 축하 화면** — 스테이지가 오르면 짜잔! 🎉

## 🛠 실행 방법

1. Mac에서 **Xcode 16 이상**을 설치해요
2. `ExercisePrincess.xcodeproj`를 더블클릭해서 열어요
3. 상단에서 시뮬레이터(예: iPhone 16)를 고르고 **▶ Run** (⌘R)
4. 실제 아이폰에 넣으려면 Xcode에 Apple ID를 등록하고(Settings → Accounts), 프로젝트의 Signing & Capabilities에서 팀을 선택한 뒤 아이폰을 연결해 실행해요

- 최소 지원 버전: iOS 17.0
- 데이터는 기기에만 저장돼요 (UserDefaults)

## 🧱 코드 구조

```

├── GameState.swift            # 게임 상태 & 저장 로직
├── Theme.swift                # 파스텔 핑크 테마 🎀
├── ContentView.swift          # 탭 구성
├── HomeView.swift             # 메인 화면 (공주님의 집)
├── WorkoutLogView.swift       # 운동 기록 시트
├── HistoryView.swift          # 운동 일기
├── StoryView.swift            # 성장 로드맵
└── CelebrationView.swift      # 이사 축하 화면
```
